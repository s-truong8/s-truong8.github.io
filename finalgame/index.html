    Instructions

    Dans Cyberbond, vous devez sauter de plateforme en plateforme pour atteindre la plus haute distance possible. Vous gagnez lorsque vous terminez les 10 niveaux.

    Il existe différents types de plateformes dont les particularités sont essentielles pour avancer dans le jeu. Certaines vous font sauter plus haut, d'autres bougent par elles-mêmes et d'autres encore disparaissent après que vous mettiez les pieds dessus.

    Si vous allez suffisament haut, vous rencontrerez des virus dangereux. Ils vous feront perdre la partie si vous les touchez.

    Pour bouger à gauche, appuyez sur A et pour bouger à droite, appuyez sur D. La touche ESPACE vous permet de sauter. Sachez que si vous dépassez les bordures latérales du jeu, vous serez replacé au côté opposé de l'écran. Utile pour vous créer de nouveaux chemins.

    Si vous ne vous sentez pas assez mis au défi, vous pouvez activer le mode difficile dans les paramètres. Dans ce mode, le jeu avance automatiquement et vous ne pouvez pas attendre. Bonne chance à vous!
